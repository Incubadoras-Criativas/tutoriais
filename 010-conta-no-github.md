# Tutorial 1 — Sua conta no GitHub

**Objetivo:** ao final deste tutorial, você terá uma conta no GitHub, protegida com verificação em duas etapas, e fará parte da organização **Incubadoras-Criativas**, onde fica o código do Território Inteligente.

**Tempo estimado:** 30 a 40 minutos.

---

## O que é o GitHub?

O GitHub é o lugar onde o código do nosso aplicativo vai morar. É como um Google Drive para código, só que guardando **toda a história** do projeto: quem mudou o quê, quando e por quê.

Cada vez que você fizer uma parte do aplicativo, ela vai ficar registrada com o seu nome. Isso é o seu **portfólio**: qualquer pessoa, inclusive uma empresa, pode ver o que você construiu.

---

## Antes de começar, confira

- [ ] Você sabe a senha do seu **e-mail** e consegue abrir ele agora (no celular ou no computador)
- [ ] Você está com seu **celular**, com bateria

Se faltar algum desses, avise o educador. Você pode fazer a atividade em dupla com um colega e terminar depois.

---

## Passo 1 — Criar a conta

1. Abra o navegador e acesse **https://github.com/signup**
2. Digite o seu **e-mail** e clique em continuar.
3. Crie uma **senha** forte: pelo menos 15 caracteres, ou 8 caracteres com números e letras minúsculas. Uma frase funciona bem, por exemplo: `minha-academia-tem-barra-fixa`
4. Escolha o seu **nome de usuário** (username). Leia as dicas abaixo antes!
5. Resolva o desafio de verificação (o "não sou um robô").
6. O GitHub manda um **código para o seu e-mail**. Abra o e-mail, copie o código e cole na página.
7. Se perguntar qual plano você quer, escolha o **gratuito (Free)**.

### Dicas para o nome de usuário

O nome de usuário vai aparecer em tudo que você fizer no projeto. Pense bem:

- Use **letras minúsculas**, números e hífen. Ex.: `ana-dev`, `jp-codigo`, `kaua2026`
- **Não use** seu nome completo nem seu sobrenome. Seu perfil é público.
- Evite nomes que você teria vergonha de mostrar numa entrevista de emprego daqui a 5 anos 😉

> **Anote seu nome de usuário e sua senha** num lugar seguro. Você vai precisar deles em toda aula.

## Passo 2 — Ativar a verificação em duas etapas (2FA)

O GitHub exige que quem escreve código tenha a **verificação em duas etapas**. Funciona assim: além da senha, para entrar você precisa de um código que aparece no seu celular. Assim, mesmo que alguém descubra sua senha, não consegue entrar na sua conta.

### 2.1 Instale um app autenticador no celular

Escolha **um** destes, na loja de aplicativos do seu celular (todos são gratuitos):

- **Google Authenticator**
- **Microsoft Authenticator**
- **GitHub Mobile** (o app oficial do GitHub)

### 2.2 Ative no GitHub

1. No GitHub, clique na **sua foto** (canto superior direito) e depois em **Settings** (Configurações).
2. No menu da esquerda, clique em **Password and authentication** (Senha e autenticação).
3. Clique em **Enable two-factor authentication** (Ativar autenticação em duas etapas).
4. Vai aparecer um **QR Code** na tela.
5. Abra o app autenticador no celular, toque em **adicionar** (geralmente um **+**) e **escaneie o QR Code**.
6. O app vai mostrar um **código de 6 números**, que muda a cada 30 segundos. Digite esse código no GitHub.

### 2.3 Anote os códigos de recuperação ⚠️

O GitHub vai mostrar uma lista de **códigos de recuperação**. **Este é o passo mais importante do tutorial.**

Se você perder ou trocar de celular, esses códigos são o **único jeito** de entrar de novo na sua conta.

- **Anote todos os códigos no papel** e guarde em casa, num lugar seguro.
- Ou clique em **Download** e guarde o arquivo num lugar que não seja só o celular.
- **Não mostre** esses códigos para ninguém.

Só depois de guardar os códigos, clique para confirmar e terminar.

## Passo 3 — Entregar seu nome de usuário ao educador

O educador precisa do seu nome de usuário para te convidar para a organização do projeto.

Entregue seu **nome de usuário** (só o nome de usuário, **nunca a senha**) da forma que o educador indicar na aula.

---

## Passo 4 — Aceitar o convite

Quando o educador te convidar, você vai receber o convite de **duas formas**:

- Um **e-mail** do GitHub dizendo que você foi convidado para a organização **Incubadoras-Criativas**
- Um aviso no **sininho** 🔔 de notificações, no canto superior direito do GitHub

Se nenhum dos dois aparecer, acesse diretamente:

**https://github.com/orgs/Incubadoras-Criativas/invitation**

Clique em **Join Incubadoras-Criativas** (Entrar). Pronto!

---

## Passo 5 — Conferir se deu tudo certo

Acesse o repositório do projeto:

**https://github.com/Incubadoras-Criativas/territorio-inteligente**

Se você está vendo os arquivos do projeto, **parabéns: você faz parte da equipe de desenvolvimento do Território Inteligente!** 🎉

## Deu problema?

| Problema | O que fazer |
| --- | --- |
| Não chegou o código no e-mail | Olhe a pasta de **spam** ou **promoções**. Espere 2 minutos e peça para reenviar. |
| "Username is not available" | Esse nome já existe. Tente outro, por exemplo acrescentando números. |
| O QR Code não escaneia | Aumente o brilho da tela do celular, ou use a opção de digitar o código manualmente (*enter this text code*). |
| O código de 6 números dá erro | Confira se o relógio do celular está no horário automático e digite o código antes de ele mudar. |
| Esqueci a senha | Na tela de login, clique em **Forgot password?** e siga as instruções que chegam no e-mail. |
| Não recebi o convite | Confirme com o educador se o nome de usuário foi digitado certo. Depois acesse o link do Passo 4. |
| Perdi o celular | Entre usando um dos **códigos de recuperação** que você anotou. É para isso que eles servem! |

## O que aprendemos

- **Conta no GitHub:** sua identidade como desenvolvedor ou desenvolvedora.
- **Verificação em duas etapas:** a senha sozinha não basta para proteger uma conta.
- **Organização:** um grupo no GitHub que reúne pessoas e projetos de uma equipe.
